# Fonts

Contract PDFs need a font that has Korean glyphs (the built-in PDF fonts have none).

- `NotoSansKR-Regular.ttf`, `NotoSansKR-Bold.ttf` — Noto Sans KR by Google, SIL Open Font License 1.1 (`OFL.txt`).
- Source: https://fonts.google.com/noto/specimen/Noto+Sans+KR → Get font → Download → `static/` folder.
- Covers Korean, Latin (English, Uzbek) and digits, so one font serves all three languages.
